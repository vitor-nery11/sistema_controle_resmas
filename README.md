# Controle de Resmas

O Controle de Resmas é um sistema desenvolvido para registrar, acompanhar e analisar o consumo de resmas de papel por diferentes setores de uma organização.

O projeto foi criado para resolver a dificuldade de controlar o uso de papel, permitindo identificar setores com maior consumo, acompanhar o histórico de utilização e gerar relatórios para auxiliar na tomada de decisões e redução de desperdícios.

## Funcionalidades

- Cadastro de setores
- Registro de consumo de resmas
- Consulta de histórico de consumo
- Geração de relatórios
- Exibição do consumo por setor
- Armazenamento persistente dos dados
- Menu interativo via terminal

## Tecnologias Utilizadas

- Python
- JSON
- Git
- GitHub

## Como Usar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/controle-de-resmas.git
```

### 2. Acesse a pasta do projeto

```bash
cd controle-de-resmas
```

### 3. Execute o programa

```bash
python main.py
```

### 4. Utilize o menu interativo

O sistema apresentará um menu com as opções disponíveis para cadastro, consulta e geração de relatórios.
